Automation

Daily threat-intel pipeline

GitHub Actions, Python, Gemini API

Running daily

Publishes a sourced threat briefing to this site every morning with no manual work.

  • Pulls the last 30 hours from CISA, BleepingComputer, The Hacker News, Krebs on Security and SecurityWeek, plus new entries in CISA's Known Exploited Vulnerabilities catalog
  • Gemini picks and summarizes up to three stories using only those articles; the code writes every source link itself
  • Stories that don't match a real article, or mention a CVE their source doesn't, are dropped. No real news means no post.
  • Runs on GitHub's built-in token with least-privilege permissions, so there's no personal key to expire

Lesson learned: the first version asked an AI for "today's news" without internet access, and it invented stories. I removed all 189 of those posts and rebuilt the pipeline around real sources and validation. Full write-up.

Web and WordPress

WordPress security plugins: Spanish localization

Open-source contributor to Jeremy Anderson Tech

Shipped in official releases

Jeremy Anderson, my mentor, asked me to contribute to his company's two free security plugins on WordPress.org. I translated both into Spanish, then tested every feature on a local WordPress VM to make sure nothing broke. Both translations were merged and shipped, and I'm listed as a contributor on both WordPress.org plugin pages.

  • JAT Site Shield (login lockouts, two-factor codes, core hardening, an activity log with email alerts, file integrity checks): translated more than 360 interface strings, and changed the code so severity labels and relative times like "5 minutes ago" could be translated too. Shipped in version 1.1.1 on Nov 4, 2026; version 1.1.2 added me as a contributor.
  • JAT Shell Scanner (checks whether a site was exposed to, or compromised by, the 2026 PHP2Shell and wp2shell attacks): translated the whole interface, 296 strings, through my own pull request #18. Released in version 1.7.1 on Nov 15, 2026.
"Spanish (es_ES) translation of the whole interface (296 strings), by Jean Berrios."JAT Shell Scanner changelog, version 1.7.1

What I learned: how WordPress localization works (.pot templates, .po and .mo files, text domains), contributing through forks and pull requests, and testing a security tool after changing it, because a translation that breaks a security feature is worse than no translation.
